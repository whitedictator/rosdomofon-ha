# Проверка 1.5.0b2

Проверено локально 5 ноября 2026 года, Home Assistant 2026.10.4, Python 3.14:

- `pytest tests/ -q` — 84 теста прошли.
- `ruff check custom_components tests` — ошибок нет.
- `git diff --check` — ошибок нет.
- В браузере: номер отображается, таймер убывает, после истечения появляется кнопка перезапроса; нажатие вызывает обработчик интеграции, меняет запрос и запускает новый отсчёт.
- В HTTP-тесте настоящий config flow HA завершает авторизацию после подтверждения API; до подтверждения токены не запрашиваются.
- Перезапрос с неверной защитой запрещён, повторный запрос во время активного подтверждения запрещён, секреты не попадают в HTML/status, сеанс очищается после отмены.
- Бинарный датчик проверен через EntityComponent HA: off → on → off → unavailable, с отпиской при удалении.

Браузерная демонстрация использует тестовый ответ сервиса и не выполняет реальный звонок. Вход по настоящему подтверждающему звонку был проверен отдельно на одном аккаунте. Реальный входящий звонок с панели и RDNP-завершение ещё не проверены; функция приёма звонков экспериментальная. Эти тесты не являются обещанием совместимости со всеми региональными провайдерами и версиями API.

- Регрессия потери соединения: при занятом reset-lock поток чтения завершается после трёх ошибок; производственный приёмник использует этот лимит и очищает клиента.
